# Calibration measurement lifetime
Shares the authoritative App auth with StrideCalibrationScreen and remounts by account. Each measurement has a lifetime generation and original account guard. A delayed permission response, GPS callback or motion callback cannot continue a retired attempt. Layout cleanup stops both sensors and invalidates the attempt; reset invalidates queued callbacks before starting a new one. A synchronous pending flag prevents duplicate preparation/saves and reset during a pending save. Height stays fixed while preparing. A background transition during start, walking or end marks the measurement interrupted; the existing assessment rejects it. Save verifies the original measurement generation and server identity before updating derived metadata, and checks returned identity afterward. The underlying SDK operation is not atomically bound to the UI guard and dispatched writes cannot be undone. No raw coordinate uploads, change to calculation, race scoring, CSS or hosted database. Five regression tests cover deferred permission, same-account relogin, deferred identity and integration contracts. Physical iPhone permission, background and account-switch tests remain required.

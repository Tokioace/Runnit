# 1v1 GPS measurement hardening — 2026-11-25

This changes only the live 1v1 client measurement, not its UI layout, backend permissions, or result eligibility. Use straight-line displacement (same experimental model as Ghost Run) for straight 50/75/100 m sprints, rather than summing GPS oscillations. A fresh accurate pre-start map fix is preferred; otherwise the first accepted post-start fix anchors the run and may undercount early movement. A finish needs two accepted fixes beyond the target; time is interpolated between fixes, independent of callback delivery latency. These are experimental estimates, not verified sport results. Only aggregate measurements are submitted.

Before release, run the two-device matrix and independent reference timing on safe straight tracks. Test a fresh and missing start fix, stationary phone, delayed fixes, GPS dropout, both runners crossing close together, phone placement, and screen lock. Check whether fallback origins and GPS gaps require explicit invalidation. Compare the estimated times with independent timing; measure failure rates. Do not treat absent steps as proof of cheating. Server-side result validation, replay/rate protection and official ranking eligibility remain separate tasks. No live database migration or production deployment is included.

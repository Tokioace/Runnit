The test-only erasure helper is intentionally excluded from the candidate bundle. Successful CI archives the bundle and manifest for seven days. This proves transactional DDL rehearsal in the synthetic schema, not recovery from a live failure or reversal of committed account deletions. The exclusive locks are rehearsal-only, not an approved production lock strategy. Before any real migration: isolated Supabase API tests, reviewed live catalog/ACL diff, backups/restore drill, maintenance and rollback plan, and explicit user approval. No remote database is connected by the generator, and no hosted migration is activated.

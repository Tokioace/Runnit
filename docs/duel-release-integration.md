## Offline verification of archived rehearsal artifacts
The CI artifact `runnit-db-rehearsal-bundle` is a disposable-only test package, not a production migration. After downloading and extracting it, check out the exact source commit used to generate it and run `python3 scripts/build-release-rehearsal.py --verify /path/to/extracted/bundle` from that checkout. The verifier regenerates the package from reviewed SQL source and compares the two SQL files and manifest byte-for-byte. Missing, extra, symlinked or mismatched files fail verification. Do not trust a manifest in isolation. This performs no database connection and does not authorize live execution. CI exercises the verifier with synthetic files before the isolated PostgreSQL rehearsal. Actual hosted test and production migration approvals remain separate.

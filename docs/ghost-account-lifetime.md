# Private run screen account lifetime
Home dashboard, stats and Ghost Run now remount when the authoritative App account ID changes. This prevents a previous user's cached history, goal draft or unsaved diagnostic run from being rendered in the next account. Ghost Run shares App auth; synchronous layout cleanup retires the measurement lifetime, stops GPS, clears the active phase and drops in-memory traces. Deferred permission and active-duel responses check both lifetime and account generation before starting sensors. Duplicate preparation is suppressed while pending. Summary insertion is still explicitly owner-scoped; late save responses cannot update a retired screen. Already dispatched requests cannot be undone, and RLS remains authoritative. No database, ranking, styling or sensor algorithm changes. Unsaved measurements are intentionally discarded on leaving the screen/account switch, not transferred to another account. Five tests exercise lifetime and account generation and check route/sensor integration. Real iPhone permission and account switch tests remain required. Stride calibration is a separate remaining audit item.
